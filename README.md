# تعريب MineMogul | MineMogul Arabic

<div dir="rtl">

تعريب كامل لـ MineMogul (نسخة ستيم 0.4.0.8): القوائم والإعدادات والأدوات والآلات والمتجر والمهام والأبحاث والخرائط والرسائل. العربية تنضاف كلغة جديدة، والإنجليزية وباقي اللغات تبقى مثل ما هي، والنص العربي يطلع من اليمين لليسار.

التعريب ما يحتوي أي ملف من ملفات اللعبة. البرنامج يعدّل ملفات اللعبة اللي عندك أنت ويحفظ نسخة من الأصلية.

## اللي تحتاجه

1. نسخة ستيم من MineMogul، **الإصدار 0.4.0.8** (رقم البناء 25312257).

## الخطوات

1. سكّر اللعبة.
2. حمّل `MineMogul-Arabic-1.0.zip` من [Releases](../../releases/latest) وفك ضغطه.
3. افتح `MineMogulArabic.exe`. إذا طلعت رسالة "Windows protected your PC" اضغط More info ثم Run anyway (البرنامج مو موقّع رقميًا).
4. اختر مجلد اللعبة (`steamapps\common\MineMogul`، البرنامج يلقاه بنفسه غالبًا) واضغط «ثبّت التعريب».
5. شغّل اللعبة: Settings ← General ← Language ← **العربية**.

## الإزالة
افتح `MineMogulArabic.exe` واضغط «أزل التعريب». ترجع ملفاتك الأصلية من النسخة الاحتياطية.

## ملاحظات
- إذا حدّثت ستيم اللعبة، ملفات التعريب ترجع لأصلها. ثبّت إصدار التعريب اللي يناسب التحديث.
- باقي بالإنجليزي: كم كلمة قليلة مكتوبة داخل كود اللعبة (مثل Node وDeposit Hopper في ماسح الموارد)، ولوحة الأخبار من الإنترنت.
- الخط: Liberation Sans مع Noto Sans Arabic (رخصة SIL Open Font License 1.1).
- كود البرنامج موجود في مجلد [`app`](app) في هذي الصفحة، وتقدر تبنيه بنفسك بـ `build.cmd`.

## English

Complete Arabic translation of MineMogul (Steam version 0.4.0.8): menus, settings, tools and machines, shop, quests,
research, maps and messages. Arabic is added as a new language; English and the other languages stay as they are, and
Arabic text reads right to left.

No game file is included. The program patches the game files of your own copy and keeps a backup of the originals.

### What you need

1. The Steam version of MineMogul, **version 0.4.0.8** (build 25312257).

### Steps

1. Close the game.
2. Download `MineMogul-Arabic-1.0.zip` from [Releases](../../releases/latest) and extract it.
3. Open `MineMogulArabic.exe`. If "Windows protected your PC" appears, click More info, then Run anyway (the program is
   not digitally signed).
4. Choose the game folder (`steamapps\common\MineMogul`; the program usually finds it) and click "Install".
5. Start the game: Settings > General > Language > **العربية**.

### Uninstall
Open `MineMogulArabic.exe` and click "Uninstall". Your original files come back from the backup.

### Notes
- If Steam updates the game, its files go back to the originals. Install the translation version made for that update.
- Still in English: a few words written in the game's code (such as Node and Deposit Hopper in the Resource Scanner), and
  the online news panel.
- Font: Liberation Sans with Noto Sans Arabic (SIL Open Font License 1.1).
- The program's source is in the [`app`](app) folder; you can build it yourself with `build.cmd`.
